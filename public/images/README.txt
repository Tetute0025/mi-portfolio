IMÁGENES DEL PORTFOLIO

Los SVG incluidos son ilustraciones provisionales para que la web no tenga imágenes rotas.
Puedes sustituirlos por tus propias fotos o capturas.

Ejemplo para cambiar la imagen del homelab:
1. Copia tu foto en esta carpeta, por ejemplo homelab.jpg.
2. Abre src/pages/proyectos.astro.
3. Busca /images/homelab-placeholder.svg.
4. Sustitúyelo por /images/homelab.jpg.
5. Guarda el archivo.

Formatos recomendados: .jpg, .png, .webp o .svg. Evita subir capturas que muestren IPs privadas, nombres de usuario, tokens, claves, direcciones de acceso o paneles administrativos.
